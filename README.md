# meikipop-ru-dict
Русский словарь для [meikipop](https://github.com/rtr46/meikipop).

Собран из **полного-многоязычного JMdict** (в отличие от стандартной сборки meikipop, которая использует англо-японский `JMdict_e.gz`). Только с выборкой по русскому языку вместо английского.

## Как использовать
Замените файл в папке данных приложения:
 - **Windows:** `%LOCALAPPDATA%\meikipop\dictionary.pkl`
 - **Linux:** `~/.config/meikipop/dictionary.pkl`
 - **macOS:** `~/Library/Application Support/meikipop/dictionary.pkl`

## Нюанс
Словарь собран из двух разных источников и только один из них содержит русский. 

## Причины
**JMdict** (полная версия, не `JMdict_e.gz`) - это многоязычный словарь. Русских переводов в нём меньше, чем английских. Около треть от общего числа. Поэтому часть редких слов может отсутствовать.

**KANJIDIC2** - отдельная база данных, из которой берутся значения отдельных иероглифов/подписи их компонентов. Она **не содержит русских переводов** - там доступны только английский и несколько других языков.

## Лицензия
Данные - [JMdict/KANJIDIC](https://www.edrdg.org) (EDRDG, CC BY-SA 4.0). 

Код сборки основан на скрипте `build_dictionary.py` из оригинального проекта [rtr46/meikipop](https://github.com/rtr46/meikipop) (лицензия GPL-3.0), с тремя правками для переключения языка на русский.
